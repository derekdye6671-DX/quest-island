# P1：角色与收藏（等待 Claude 审核）

基线：正式 main `dbbd620`（P0）。此分支仅实施 P1，不含 P2。不合并 main。

## 文件与范围

- `index.html`：图片区域独立 `button[data-view]`，购买/换上按钮与处理逻辑原样保留；两列手机收藏卡片；独立原生 `#imageViewer` 弹层；9:16 + contain（≤70vh）；Esc/遮罩/关闭按钮退出，Tab/Shift+Tab 循环，焦点回原卡片（重渲染后按 ID/区域查找）；稳定图片尺寸、占位和失败重试。奖励弹层 `#ov` 仍独立，只完善图片完整显示。
- 原始 25 张素材不纳入公开仓库，存放位置由用户另行决定；本分支不包含 `assets/originals/`。原有 `img/` 网页素材保持不变。
- 本目录：前后截图和测试结果，不参与应用运行。

## 审核约束解释

已开放未购买衣橱（open && !own && !hidden）恢复普通缩略图，不提供 data-view。已拥有的非隐藏造型显示缩略图并提供大图。未开放且未拥有的造型、隐藏款 l16、未解锁图鉴使用占位，不插入原图元素或查看入口，条件文字仍可见。图片按钮仅包图片与查看提示，不覆盖名称或购买按钮。图鉴没有购买逻辑。

对 l16 采用保守解释：即使集齐图鉴，也不提供独立大图按钮；衣橱内即使已拥有也只显示占位；穿戴、首页和正常奖励画面按原逻辑保持不变。查看处理器重新核验解锁资格，伪造 data-view 也不能通过查看入口展示未解锁图。

查看、关闭、图片重试不修改 LOG/WK/EX/SUB/PRO/PR，不调用奖励处理或写 localStorage。不新增依赖，不新增外部图片。查看资格只读取现有结果，不修改解锁条件。

原有 24 张 JPG、plan.json、verified.json、manifest 和 sw.js 与 P0 字节一致。图片仍保留 lazy/async，只有截图采集时在隔离上下文等待整页延迟图片加载，以免长截图出现尚未加载的空位。

## 验证结果

详细结果见 `test-results.json`。使用 Chromium + Playwright、隔离浏览器、Asia/Shanghai，未用真实用户本地数据。

- 原版/新版空记录和 84 天全记录对照：金币、XP、等级、连击、Boss、图鉴/自动解锁和导出相同。
- 普通购买/装备、23 个允许的大图入口，隐藏 l16 无入口。
- 已开放未购买仅普通缩略图，无大图；未开放未拥有和 l16 无原图；伪造入口被拒；查看时 storage/coins 不变。
- Esc、遮罩、关闭、键盘焦点循环，以及 render 后焦点恢复。
- 缩略图/弹层网络失败均可重试，页面无 JS 错误。
- 五种尺寸、两种主题、四个页面，共 40 组改后布局无水平溢出；弹层在视口内且图片≤70vh。
- 已浏览图片在离线重载后可再次完整查看。原始素材不进入公开分支，24 张现有网页素材未替换。

未测：iOS/Android 真机安全区、真机安装、实际辅助技术；业务全排列非穷举。浏览器反馈测试不代表真实验收操作。
