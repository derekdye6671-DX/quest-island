# 冒险岛

十二周学习计划的打卡网页，可以装到手机桌面使用。

- **打开：** https://derekdye6671-dx.github.io/quest-island/
- **装到手机桌面：** 安卓 Chrome 点右上角菜单 →「添加到主屏幕」或「安装应用」；iPhone Safari 点分享 →「添加到主屏幕」
- **数据存在哪：** 打卡、金币、衣橱都只存在你自己手机的浏览器里，不上传。换手机或清理浏览器前，先点「💾 备份」导出文件
- **验收：** 点「提交验收」，把自动复制的申请发给 Claude；Claude 验收后更新 `verified.json`，回到网页点「🔄 刷新验收」
- **同步 Grok 版：** 点「⬇ 导出给 Grok」，得到 `quest12-checkins.json`

## 文件

| 文件 | 内容 | 谁改 |
| --- | --- | --- |
| `index.html` | 网页本身 | Claude |
| `plan.json` | 12 周计划 | Claude |
| `verified.json` | 验收清单：任务编号 + 一句结论，不含个人数据 | Claude |
| `manifest.webmanifest`、`sw.js`、`icons/` | 让网页能装到桌面、断网也能打开 | Claude |

## 自己添加奖励图（本地功能）

在「本地奖励图」点「＋ 添加奖励图」，选择本机 JPG/PNG/WebP、填写名称并设置类型与条件：

- **衣橱**：达到条件后用金币兑换，能换到角色卡；不减少 XP。
- **收藏 / 隐藏款**：按等级、连续全勤、Boss、原有图鉴等条件免费领取。隐藏款领取前不展示图。
- 编辑、归档都保留已获奖励；奖励库独立于当前十二周计划，未解锁也能留到后续计划。历史条件按本机保存的历轮最高/已达成记录判断，不把视频次数跨轮相加。

图片只在当前浏览器的 IndexedDB 中，不上传，不自动读取桌面文件夹，不自动同步其他手机或 Claude。单张≤8 MB、总计≤80 MB / 100项，不支持 HEIC/SVG/图片网址。换手机或清理前点「💾 备份」导出**含图片 v2 备份**，安全保存，不要提交到公开仓库。新版可导入旧 v1 备份（保留当前图片库）；旧页面不识别 v2。

开发验证：`npm ci && npm run check && npm test`（页面无需构建/运行依赖）。修改说明、数据边界和手机验收清单见 [`docs/LOCAL-REWARDS-REVIEW.md`](docs/LOCAL-REWARDS-REVIEW.md)。
