规则说明

🧭 第一原则把「学多少技术」让位于「你能否独立用起来」。凡是要敲命令的步骤都由 Claude Code 执行，你看懂并批准；你要会的是启动工具、准备输入、判断结果、出错时停下并恢复。
📦 放哪个仓库作品、脚本、网页放 xiaoxuanzi-channel（公开）；计划、进度、交接放 ai-12week-lab（私有）。任务里没特别说明的「仓库」都指 xiaoxuanzi-channel。真实健康数据、工作资料不进任何仓库，练习用模拟数据。

🔍 验收所有验收类任务（主技术块、Claude Code 关、GitHub 关、ChatGPT / Gemini / Grok 交付）都由 Claude 确认：按任务里写的「验收证明」发给 Claude，确认后才发金币。
